## Зачем это нужно

Почти любая программа где-то хранит данные: заказы в магазине, пользователей в приложении, транзакции в банке. **SQL** (Structured Query Language) — язык, на котором мы *спрашиваем* у базы данных: «покажи», «посчитай», «найди». Это один из самых долгоживущих и востребованных навыков в IT: аналитики, разработчики, тестировщики и менеджеры продуктов используют его ежедневно.

В этом курсе вы будете работать с учебной базой интернет-магазина **«ТехноМаркет»**. Справа (или внизу на телефоне) всегда доступна схема: какие есть таблицы и столбцы.

## Таблица — это строки и столбцы

Данные в реляционной базе лежат в **таблицах**. Таблица похожа на лист в Excel:

- **столбец** (column) — один атрибут, например `name` или `price`; у каждого столбца свой тип данных;
- **строка** (row, запись) — один объект: один товар, один клиент.

Нажмите «Запустить» — запрос покажет всё содержимое таблицы `categories`:

```sql try
SELECT * FROM categories;
```

## Анатомия запроса

```sql
SELECT   что_показать
FROM     откуда_взять;
```

- `SELECT` — перечисляет **столбцы**, которые попадут в результат.
- `FROM` — называет **таблицу**.
- `*` означает «все столбцы».
- Точка с запятой завершает запрос (в одиночных запросах она необязательна, но привычка полезна).

Выберем только нужные столбцы — через запятую:

```sql try
SELECT name, city
FROM customers;
```

Порядок столбцов в результате — тот, в котором вы их перечислили. Попробуйте поменять `name` и `city` местами.

## Псевдонимы (AS)

Столбцу в результате можно дать другое имя — **псевдоним**. Он влияет только на результат, а не на таблицу:

```sql try
SELECT name AS title, price AS price_rub
FROM products;
```

> **Совет.** Ключевые слова (`SELECT`, `FROM`) можно писать в любом регистре, а переносы строк и отступы — на ваш вкус. Профессионалы пишут ключевые слова заглавными и каждую часть запроса — с новой строки: так запрос читается как текст.

## Простые вычисления

`SELECT` умеет не только доставать данные, но и вычислять. `FROM` в таком случае не нужен:

```sql try
SELECT 2 + 3 AS total, 'привет' AS greeting;
```

## Типичные ошибки

> **Забытая запятая.** `SELECT name city FROM customers` — не ошибка! SQL решит, что `city` — это *псевдоним* для `name`, и вернёт один столбец. Если столбцов вышло меньше, чем вы хотели, ищите пропущенную запятую.

> **Опечатка в названии.** Название таблицы или столбца должно совпадать с тем, что в схеме. Сообщение `no such column` — верный признак опечатки.

## Запомните

- `SELECT` выбирает столбцы, `FROM` — таблицу.
- `*` — все столбцы; через запятую — нужные.
- `AS` задаёт имя столбца в результате.
- Пропущенная запятая между столбцами превращает второй столбец в псевдоним.
