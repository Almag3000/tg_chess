## SELECT умеет вычислять

В `SELECT` можно писать не только названия столбцов, но и **выражения**: арифметику, склейку строк, вызовы функций. Выражение вычисляется для каждой строки отдельно.

```sql try
SELECT name, price, price * 1.2 AS price_with_vat
FROM products;
```

Арифметика: `+`, `-`, `*`, `/`, `%` (остаток от деления).

> **Ловушка целочисленного деления.** Если делить целое на целое, результат тоже будет целым: `7 / 2` даёт `3`, а не `3.5`. Чтобы получить дробь, сделайте одно из чисел дробным: `7 * 1.0 / 2` или `7 / 2.0`.

```sql try
SELECT 7 / 2 AS int_div, 7 / 2.0 AS real_div, 7 % 2 AS remainder;
```

## Строки

Склейка строк — оператор `||`. Рядом живут функции:

| Функция | Что делает |
|---|---|
| `LENGTH(s)` | длина строки |
| `UPPER(s)`, `LOWER(s)` | регистр (в SQLite — только для латиницы) |
| `SUBSTR(s, start, len)` | подстрока; нумерация символов с 1 |
| `INSTR(s, part)` | позиция подстроки (0, если не найдена) |
| `REPLACE(s, from, to)` | замена |
| `TRIM(s)` | убрать пробелы по краям |

```sql try
SELECT name || ' (' || city || ')' AS label,
       LENGTH(name) AS name_len
FROM customers;
```

Комбинируем функции: вырежем домен из email — всё, что после `@`:

```sql try
SELECT email,
       SUBSTR(email, INSTR(email, '@') + 1) AS domain
FROM customers
WHERE email IS NOT NULL;
```

## Числа

`ROUND(x, n)` — округление до `n` знаков, `ABS(x)` — модуль, `MIN(a, b)`/`MAX(a, b)` с несколькими аргументами выбирают меньшее/большее значение **в пределах строки**.

```sql try
SELECT name, ROUND(price / 3, 2) AS third
FROM products
LIMIT 5;
```

## Порядок выполнения

Выражения в `SELECT` вычисляются **после** `WHERE`. Поэтому псевдоним, придуманный в `SELECT`, в `WHERE` обычно использовать нельзя — на момент фильтрации его ещё нет. Повторяйте выражение целиком:

```sql try
SELECT name, price * stock AS stock_value
FROM products
WHERE price * stock > 500000;
```

## Диалекты SQL

SQL — стандарт, но у каждой СУБД свои «акценты». Мы учимся на **SQLite** (она встроена в телефоны и браузеры). Основа одинакова везде, различаются детали: склейка строк (`||` или `CONCAT()`), даты, `LIMIT` против `TOP`. Мы будем отмечать такие места.

## Запомните

- В `SELECT` можно использовать выражения и функции; они считаются построчно.
- Целое / целое = целое; для дроби добавьте `.0` или `* 1.0`.
- `||` склеивает строки, `SUBSTR`/`INSTR`/`LENGTH` разбирают их.
- Псевдонимы из `SELECT` недоступны в `WHERE`.
