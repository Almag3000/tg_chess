## Как SQLite хранит даты

В SQLite нет отдельного типа «дата». Даты хранятся как **текст в формате ISO-8601**: `'2025-03-14'` (или `'2025-03-14 18:30:00'`). Этот формат удобен тем, что строки сравниваются так же, как даты: чем позже дата — тем «больше» строка.

```sql try
SELECT id, order_date
FROM orders
WHERE order_date >= '2025-03-01' AND order_date < '2025-04-01';
```

> **Правило полуинтервала.** Чтобы выбрать «весь март», берите `>= '2025-03-01' AND < '2025-04-01'`, а не `BETWEEN … AND '2025-03-31'`: если в столбце есть время (`'2025-03-31 15:00'`), последний день потеряется.

## Функции даты

| Функция | Пример | Результат |
|---|---|---|
| `date(x, модификаторы…)` | `date('2025-03-14', '+10 days')` | `2025-03-24` |
| `strftime(формат, x)` | `strftime('%Y-%m', '2025-03-14')` | `2025-03` |
| `julianday(x)` | разность двух значений — дни | число |
| `'now'` | `date('now')` | сегодня (UTC) |

Часто нужные коды `strftime`: `%Y` — год, `%m` — месяц, `%d` — день, `%w` — день недели (0 = воскресенье), `%H` — час.

```sql try
SELECT order_date,
       strftime('%Y-%m', order_date) AS month,
       strftime('%w', order_date)    AS weekday
FROM orders
LIMIT 5;
```

## Разница между датами

Вычесть даты напрямую нельзя (это строки). Переведите их в юлианские дни:

```sql try
SELECT name, signup_date,
       CAST(julianday('2025-06-01') - julianday(signup_date) AS INTEGER) AS days_since
FROM customers;
```

## Сдвиги

Модификаторы `'+N days'`, `'-N months'`, `'start of month'`, `'+1 year'` позволяют «шагать» по календарю:

```sql try
SELECT date('2025-03-14', 'start of month') AS month_start,
       date('2025-03-14', 'start of month', '+1 month', '-1 day') AS month_end;
```

> **Подвох с концом месяца.** `date('2025-01-31', '+1 month')` — это «31 февраля», которого нет. SQLite не округляет вниз, а переносит излишек на март. Проверьте сами:

```sql try
SELECT date('2025-01-31', '+1 month');
```

## Другие СУБД

В PostgreSQL вместо `strftime` — `EXTRACT`, `DATE_TRUNC`, `AGE`; в MySQL — `DATE_FORMAT`, `DATEDIFF`. Логика та же: *вытащить часть даты*, *сдвинуть дату*, *посчитать разницу*.

## Запомните

- Даты в SQLite — ISO-строки `YYYY-MM-DD`; сравниваются обычными операторами.
- Период выбирают полуинтервалом: `>= начало AND < начало_следующего`.
- `strftime` вытаскивает год/месяц/день недели; `julianday` считает разницу в днях.
- Арифметика с месяцами на границах («31-е») может удивить.
