## Когда пара не нашлась

`INNER JOIN` теряет строки без пары. Но часто нужно как раз *сохранить* их: «покажи **всех** клиентов и их заказы — даже тех, кто ничего не заказывал». Для этого есть `LEFT JOIN`:

- все строки **левой** таблицы остаются в результате;
- если для строки справа пары нет, все столбцы правой таблицы будут `NULL`.

```sql try
SELECT c.name, o.id AS order_id, o.order_date
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id
ORDER BY c.id, o.id;
```

Прокрутите результат: у клиентов, которые ничего не покупали, в столбцах заказа стоят `NULL`.

> `RIGHT JOIN` и `FULL JOIN` существуют, но практически всегда обходятся перестановкой таблиц и `LEFT JOIN`. Начинайте запрос с «главной» таблицы — той, строки которой нельзя потерять.

## Считаем вместе с нулями

Сколько заказов у каждого клиента, **включая тех, у кого их нет**?

```sql try
SELECT c.name, COUNT(o.id) AS orders
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id
GROUP BY c.id, c.name;
```

> **Почему `COUNT(o.id)`, а не `COUNT(*)`?** Клиент без заказов даёт в результате *одну* строку (с `NULL` справа). `COUNT(*)` посчитает её — получится 1. `COUNT(o.id)` пропустит `NULL` — получится честный 0.

## Поиск «без пары» (anti-join)

Из `LEFT JOIN` вытекает полезнейший приём — найти строки, у которых **нет** связанных. Оставляем только те, где справа `NULL`:

```sql try
SELECT c.name
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id
WHERE o.id IS NULL;
```

Читается: «клиенты, для которых не нашлось ни одного заказа». Проверять нужно столбец, который в правой таблице **не может быть** `NULL` сам по себе (обычно `id`).

## Ловушка: условие в WHERE или в ON

Фильтр по правой таблице в `WHERE` **убивает** `LEFT JOIN`: строки с `NULL` не проходят условие `o.status = 'delivered'`, и клиенты без заказов пропадают — получился обычный `INNER JOIN`.

Если условие относится к *соединению* («присоедини только доставленные заказы»), его место — в `ON`:

```sql try
SELECT c.name, COUNT(o.id) AS delivered_orders
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id AND o.status = 'delivered'
GROUP BY c.id, c.name
ORDER BY delivered_orders, c.name;
```

Правило: **фильтр по левой таблице — в `WHERE`, по правой — в `ON`** (если нужно сохранить левые строки).

## Запомните

- `LEFT JOIN` сохраняет все строки левой таблицы; недостающие значения справа — `NULL`.
- Для подсчёта «с нулями» используйте `COUNT(правая.id)`, а не `COUNT(*)`.
- Anti-join: `LEFT JOIN … WHERE правая.id IS NULL`.
- Условия по правой таблице пишите в `ON`, иначе `LEFT JOIN` превратится в `INNER`.
