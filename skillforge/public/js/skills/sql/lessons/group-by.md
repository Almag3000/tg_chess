## Итоги по группам

Одна цифра на всю таблицу — это скучно. Настоящая аналитика начинается с вопросов «**по каждому** городу», «**по каждому** месяцу», «**по каждой** категории». Для этого — `GROUP BY`: он делит строки на группы с одинаковым значением и применяет агрегат к каждой группе.

```sql try
SELECT city, COUNT(*) AS customers
FROM customers
GROUP BY city;
```

Мысленная модель: SQL сортирует строки в «стопки» по значению `city`, а потом для каждой стопки считает `COUNT(*)`. На каждую группу — **одна строка** результата.

## Правило столбцов

В `SELECT` разрешены только:

1. столбцы из `GROUP BY`,
2. агрегатные функции,
3. выражения из них.

Остальные столбцы бессмысленны: что показать для группы «Москва» в столбце `name` — одного из пяти клиентов?

```sql try
SELECT status,
       COUNT(*)  AS orders,
       MIN(order_date) AS first_order,
       MAX(order_date) AS last_order
FROM orders
GROUP BY status
ORDER BY orders DESC;
```

## Группировка по выражению

Группировать можно не только по столбцу, но и по вычисленному значению — например, по месяцу:

```sql try
SELECT strftime('%Y-%m', order_date) AS ym,
       COUNT(*) AS orders
FROM orders
GROUP BY ym
ORDER BY ym;
```

## Несколько столбцов

`GROUP BY city, vip` создаёт группу для каждой *комбинации* значений:

```sql try
SELECT city, vip, COUNT(*) AS customers
FROM customers
GROUP BY city, vip
ORDER BY city, vip;
```

## Порядок выполнения запроса

Это одна из самых важных идей в SQL. Пишем мы запрос в одном порядке, а **выполняется он в другом**:

1. `FROM` — берём таблицу (и соединяем, см. дальше)
2. `WHERE` — отбрасываем лишние строки
3. `GROUP BY` — собираем группы
4. `HAVING` — отбрасываем лишние *группы*
5. `SELECT` — вычисляем столбцы и псевдонимы
6. `DISTINCT`
7. `ORDER BY` — сортируем
8. `LIMIT` / `OFFSET`

Отсюда следствия: в `WHERE` нельзя ссылаться на агрегаты (групп ещё нет); `ORDER BY` может использовать псевдонимы (`SELECT` уже выполнен).

## Запомните

- `GROUP BY` делит строки на группы; на группу — одна строка результата.
- В `SELECT` — только групповые столбцы и агрегаты.
- Группировать можно по выражению и по нескольким столбцам.
- Выполняется: `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`.
