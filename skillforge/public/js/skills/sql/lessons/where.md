## Берём только нужные строки

До сих пор мы получали все строки таблицы. Реальные таблицы содержат миллионы записей, поэтому первое, что мы делаем, — **фильтруем**. За это отвечает `WHERE`:

```sql try
SELECT name, city
FROM customers
WHERE city = 'Москва';
```

Условие проверяется для **каждой** строки; в результат попадают только те, для которых оно истинно.

> **Текст — в одинарных кавычках.** `'Москва'` — строка. Двойные кавычки в стандартном SQL означают *имя столбца*, а не текст.

## Операторы сравнения

| Оператор | Смысл |
|---|---|
| `=` | равно (одно «равно», не два!) |
| `<>` или `!=` | не равно |
| `<`, `<=`, `>`, `>=` | меньше, меньше или равно, больше, больше или равно |

```sql try
SELECT name, price
FROM products
WHERE price >= 50000;
```

## Несколько условий: AND, OR, NOT

- `AND` — должны выполниться **оба** условия;
- `OR` — достаточно **одного**;
- `NOT` — отрицание.

```sql try
SELECT name, price, stock
FROM products
WHERE price < 5000 AND stock > 100;
```

> **Ловушка приоритета.** `AND` связывает сильнее, чем `OR` — как умножение сильнее сложения. Условие `A OR B AND C` означает `A OR (B AND C)`. Если сомневаетесь — ставьте скобки: они ничего не стоят и экономят часы отладки.

## Удобные сокращения

**`IN`** — значение входит в список (вместо цепочки `OR`):

```sql try
SELECT name, city
FROM customers
WHERE city IN ('Москва', 'Казань');
```

**`BETWEEN … AND …`** — диапазон, **включая** границы:

```sql try
SELECT name, price
FROM products
WHERE price BETWEEN 1000 AND 5000;
```

**`LIKE`** — поиск по шаблону: `%` — любое количество любых символов, `_` — ровно один символ:

```sql try
SELECT name
FROM products
WHERE name LIKE '%Nova%';
```

> **Нюанс SQLite.** `LIKE` игнорирует регистр только для латиницы. Для кириллицы `'а%'` и `'А%'` — разные шаблоны.

## Пустые значения — IS NULL

Иногда значение **неизвестно** — тогда в ячейке лежит специальный маркер `NULL`. Сравнивать с ним через `=` нельзя — для проверки есть `IS NULL` и `IS NOT NULL`:

```sql try
SELECT name, email
FROM customers
WHERE email IS NULL;
```

Подробнее про `NULL` — в отдельном уроке; пока запомните эту форму.

## Запомните

- `WHERE` оставляет только те строки, для которых условие истинно.
- Текст — в `'одинарных'` кавычках; «равно» — один знак `=`.
- `AND` сильнее `OR`; расставляйте скобки.
- `IN`, `BETWEEN`, `LIKE` делают условия короче; `NULL` проверяют только через `IS NULL`.
