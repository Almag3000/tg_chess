# Skillforge

Интерактивная платформа для изучения навыков. Сейчас доступен курс **SQL**: 8 модулей, 21 урок, 126 упражнений с автопроверкой. Запросы выполняются в браузере (SQLite через WebAssembly), ничего устанавливать пользователю не нужно.

## Запуск

```bash
node server/server.js          # http://localhost:8080
# переменные: PORT, HOST, DATA_DIR (где хранится прогресс, по умолчанию ./data)
```

Нужен только Node.js 18+, зависимостей нет. Можно открыть и просто `public/` любым статическим сервером — тогда прогресс хранится только в браузере (без синхронизации).

## Деплой на свой сервер без домена

**Вариант 1. HTTP по IP** — самый простой: `PORT=80 node server/server.js` (или `skillforge.service` для systemd). Сайт открывается как `http://IP-сервера`. Всё работает, но код синхронизации идёт по незашифрованному каналу.

**Вариант 2. HTTPS через sslip.io (рекомендуется).** Бесплатный DNS-сервис: имя `203-0-113-7.sslip.io` всегда указывает на IP `203.0.113.7`, поэтому Caddy выпускает для него настоящий сертификат Let's Encrypt.

```bash
echo "SITE=203-0-113-7.sslip.io" > .env   # подставьте IP вашего сервера
docker compose up -d
```
Откройте порты 80 и 443. Прогресс хранится в docker-томе `progress`.

## Как сохраняется прогресс

- Всегда — в `localStorage` браузера.
- Если доступен сервер — автоматически синхронизируется. Регистрации нет: у каждого пользователя случайный секретный код (Настройки ⚙). Чтобы продолжить на другом устройстве, введите этот код там. На сервере хранится только хэш кода.
- Слияние безопасно: решённые задачи не теряются, побеждает более свежая запись. Есть экспорт/импорт JSON.

## Методика

Теория 5–10 минут с запускаемыми примерами → упражнения по нарастающей сложности (подсказки по шагам, очки снижаются) → задачи на «исправь запрос» и вопросы на предсказание результата → интервальные повторения (1/3/7/16/35 дней) → экзамен из бизнес-кейсов без подсказок.

## Добавление нового навыка

1. Создайте `public/js/skills/<id>/index.js` с объектом навыка (см. `skills/sql/index.js`): `modules → lessons → exercises` и `runner` (`run`, `grade`, `schema`) для задач с кодом. Вопросы типа `quiz` работают без runner.
2. Тексты уроков — Markdown в `lessons/*.md` (` ```sql try ` — запускаемый пример).
3. Зарегистрируйте навык в `public/js/skills/index.js`.
