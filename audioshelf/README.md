# Книжная полка — Android

Нативная версия веб-приложения «Книжная полка» для учёта аудиокниг.

## Что умеет

- **Главная** — сколько всего книг, сколько прослушано, что слушаешь сейчас,
  какие серии можно продолжить, прогресс за год и цель, круговая диаграмма.
- **Полка** — книги корешками на полках по сериям (цвета те же, что в веб-версии)
  или списком; поиск, фильтр по статусу.
- **Серии** и **Авторы** — прогресс по каждой серии и автору; нажатие показывает
  книги на полке, долгое нажатие — переименование.
- **Карточка книги** — статус, прогресс прослушивания, оценка, даты, заметка.
- **Добавление/редактирование** — подсказки по существующим сериям и авторам,
  автор подставляется из серии, предлагается следующий том.
- **Импорт/экспорт CSV** — понимает файл, выгруженный из веб-версии, и таблицы
  Excel (`;`). Совпадающие книги обновляются, а не дублируются.
- При первом запуске на полке исходный список из 135 книг.

Данные хранятся в одном JSON-файле на телефоне, раз в день сохраняется
резервная копия (последние 10).

## Устройство

- `core/` — чистый Kotlin без Android: модель, операции, статистика, CSV,
  исходный список. Собирается и тестируется отдельно: `./gradlew -p core test`.
- `app/` — Android-приложение на Jetpack Compose.
  - `data/LibraryRepository` — чтение и атомарная запись файла библиотеки.
  - `ui/ShelfViewModel` — состояние и действия.
  - `ui/screens`, `ui/sheets`, `ui/components` — экраны, шторки, элементы.

## Тесты

- `core/src/test` — логика: статусы и даты, удаление с очисткой серий/авторов,
  порядок томов, CSV (в том числе файл веб-версии), JSON.
- `app/src/test` — Robolectric: хранилище и пользовательские сценарии
  (добавление, редактирование, удаление, фильтры, свайпы), снимки экранов.
- `app/src/androidTest` — на эмуляторе: запуск приложения, добавление книги
  с проверкой файла на диске, пересоздание активити, скриншоты с устройства.

## Сборка

CI (`.github/workflows/audioshelf.yml`) на каждый пуш прогоняет все тесты,
собирает подписанный APK и публикует его в GitHub Releases вместе со
скриншотами. Локально: `./gradlew :app:assembleRelease` (нужен Android SDK).

APK подписан ключом `app/audioshelf.jks`, лежащим в репозитории, чтобы новые
версии ставились поверх старых без удаления данных.
